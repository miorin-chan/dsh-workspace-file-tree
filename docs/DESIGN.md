# 文件目录分组设计

## 分组语义

`workspace-file-tree` 是独立的工作区分组方式。
DSH 内置 `workspace-tree` 使用已经登记的工作区作为父节点，文件目录分组还将共享但未登记的分叉目录纳入树中。
例如，`/team/api` 和 `/team/web` 会归入 `team`，即使 `/team` 未登记。
没有分叉的未登记中间目录可折叠，同名工作区沿用浏览器的路径区分。

注册工作区以工作区 ID 标识。合成目录以归一化路径标识，使用独立的键空间，隔离 Windows 盘符与 UNC 共享根。
文件目录树根据已有工作区路径计算，父节点可展开或折叠。
工作区节点继续承载自己的会话及原有操作。
合成节点只提供目录层级，只有已登记的工作区可以用于新会话选区。
工作区注册、会话成员、手动排序和归档仍由 DSH 浏览器负责。

## 接入浏览器

插件向 DSH 工作区浏览器的分组注册表提交稳定 ID、本地化名称、图标与目录层级投影，随插件启停注册和释放。
内置分组和插件分组通过同一目录生成视图选项。注册更新实时传到侧栏和快捷键弹窗。
浏览器使用现有组件绘制节点及操作，根据节点类型决定可用动作。
分组插件只提供层级，搜索、排序和菜单由浏览器负责。

插件独立启停，具备所需 DSH 接口后纳入工作区聚合包。
快捷键及分组记忆由[工作区切换器](../../dsh-workspace-welcome-switcher/docs/DESIGN.md)负责。

## 验收

- 验证共享未登记目录、已登记祖先、同名工作区、不同驱动器和 UNC 共享根的层级。
- 启停插件时，两处视图选项同步增减文件目录分组。
  活动分组失效时验证浏览器的回退行为。
- 验证原有的会话与工作区操作。新会话选区须允许展开目录、选择已登记工作区。
